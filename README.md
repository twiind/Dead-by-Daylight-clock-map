# ⏱️ Qt Timer App

Простое приложение на PyQt6 с выводом изображения на экран.

## Установка и запуск
- Запустите файл run.but
### Требования

- Python 3.7+
- PyQt6


## Как использовать

- Перемещайте ползунок, чтобы установить желаемое время (в секундах)

- Нажмите кнопку Start, чтобы запустить отсчёт

- По достижении нуля интерфейс разблокируется и значение сбрасывается
